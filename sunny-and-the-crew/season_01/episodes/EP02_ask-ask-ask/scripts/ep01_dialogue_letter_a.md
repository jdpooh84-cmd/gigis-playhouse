# EP01 "Ask Ask Ask" — Letter A Educational Dialogue Script
Episode Song: "A is Amazing"
Concept of the Day: Letter A | Featured Words: Apple, Airplane
Version 1.0 | 2026-07-06

> This script covers Act 2 (dialogue setup) and Act 4 (recap and goodbye) of EP01.
> Act 1 = Theme song (pre-produced). Act 3 = "A is Amazing" (lyric-synced animatic, see separate file).
> All stage directions are written for voice director AND animator — no interpretation required.

---

## QUALITY CHECK LOG

- [x] No sentence exceeds 8 words for leads, 6 words for younger characters (Mia)
- [x] Every concept word (A, apple, airplane, amazing) appears 3+ times per scene
- [x] Every concept word has a physical/sensory pairing (crunch for apple, wings/zoom for airplane)
- [x] Two viewer interaction pauses with 3-second holds (Scenes 1 and 2)
- [x] One warm mistake-and-correction moment (Leo says "ant" — Scene 2)
- [x] No negative language used anywhere
- [x] Emotional closure is explicit at every scene end
- [x] Song lead-in template followed (Scene 3)
- [x] Song lead-out/recap template followed (Scene 4)
- [x] All stage directions are specific enough for director and animator

## SCENE 1 — INTRO + CONCEPT INTRODUCTION

```
EPISODE: EP01 "Ask Ask Ask"
CONCEPT: Letter A | Apple, Airplane
SCENE: 1 of 5
SCENE PURPOSE: Intro / Concept Introduction
LOCATION: Sunny's Backyard (LOC_BACKYARD)
CHARACTERS: Sunny (lead), Leo (supporting), Mia (supporting)
TARGET RUNTIME: 40 seconds
EMOTIONAL BEAT GOAL: Curiosity builds to shared excitement
VIEWER INTERACTIONS: 1
```

---

### HOOK (10 seconds)

```
SUNNY
(bursts through backyard gate, spinning toward camera mid-run, pigtails bouncing,
one arm sweeping wide — she has BIG news)
"Friends! I have the BEST thing!"
```

```
LEO
(already at the picnic table, red notebook open, looks up with a startled blink,
glasses sliding down nose)
"What? What is it?"
```

```
MIA
(skipping in through the gate right behind Sunny, arms out for balance like a
tightrope walker, big curious eyes)
"What? What? What?"
```

```
SUNNY
(plants feet wide in center of yard, throws both arms open, looks directly at camera
— she is glowing)
"Today — we are learning something AMAZING."
```

[PAUSE — 1 second — pure suspense beat, no child answer needed]

```
SUNNY
(leans toward camera, eyebrows raised, voice drops to a warm whisper)
"A letter."
```

---

### CONCEPT INTRODUCTION (20 seconds)

```
SUNNY
(turns to the easel beside the picnic table, lifts the paper cover off with a
dramatic WHOOSH to reveal a large bright letter A card — bold, round, cream with a
coral border)
"Look at THIS!"
```

```
LEO
(stands from bench, tilts head, glasses sliding, pointing at the card)
"Oh — that's the letter A!"
```

```
SUNNY
(spins back to camera, arms up, eyes wide — Letter of the Day Badge animates into
frame near the card)
"The letter A!"
```

```
SUNNY
(leans directly into camera, eyebrows raised, warm smile, speaks slowly and clearly)
"Can you say it with me?"
(holds finger to ear as if listening)
"A! Say it — A!"
```

[PAUSE — 3 seconds — camera holds; Sunny's expression is open, waiting, warm; child says "A"]

```
SUNNY
(claps both hands once, then fist-pump, beaming)
"You said it! A! I heard you! Wonderful!"
```

```
MIA
(bouncing on both feet beside Sunny, hands clapping over her head)
"A! A! A!"
```

```
LEO
(marks something in notebook with a decisive stroke, grins behind glasses)
"Three A's. Well done."
```

```
SUNNY
(turns back to camera, one hand on heart, warm and steady)
"The letter A is AMAZING."
(holds up one finger)
"And today — we have TWO amazing A words."
```

---

### EMOTIONAL CLOSURE

```
SUNNY
(to camera, arms spread wide, voice warm)
"Are you ready to find them?"
```

[BOUNCE WIPE TRANSITION — all three characters run toward the easel together]

## SCENE 2 — EXPLORATION + REINFORCEMENT

```
EPISODE: EP01 "Ask Ask Ask"
CONCEPT: Letter A | Apple, Airplane
SCENE: 2 of 5
SCENE PURPOSE: Exploration / Reinforcement
LOCATION: Sunny's Backyard (LOC_BACKYARD)
CHARACTERS: Sunny (lead), Leo (supporting), Mia (supporting)
TARGET RUNTIME: 50 seconds
EMOTIONAL BEAT GOAL: Playful discovery, warm mistake correction, building pride
VIEWER INTERACTIONS: 1
```

---

### EXPLORATION — APPLE (15 seconds)

```
SUNNY
(lifts a shiny, oversized bright red apple from the picnic table basket — holds it
high so it catches the light)
"Our FIRST A word is — apple!"
```

[Chalk Word "APPLE" floats near the apple — slightly wobbly letters, coral colored]

```
MIA
(eyes go wide, leans forward, hands clasped near chin — her classic "I want this"
face)
"Apple! Apple starts with A!"
```

```
LEO
(squints at apple through glasses, pencil tapping chin)
"A is for apple. Apples are very... red."
```

```
SUNNY
(grins, pulls apple close, mimes a big dramatic crunch — LOUD sound effect)
"CRUNCH! Can you crunch like an apple?"
(leans toward camera, one hand cupped to ear, nodding encouragingly)
"Try it! Crunch!"
```

[All three characters crunch dramatically — heads dipping, shoulders popping — comic and fun]

[PAUSE — 3 seconds — child crunches along at home]

```
SUNNY
(to camera, pointing with delight)
"I heard your crunch! Apple — A — amazing!"
```

---

### EXPLORATION — MISTAKE AND CORRECTION (15 seconds)

```
LEO
(snapping notebook shut, suddenly confident — but just a little too sure of himself,
index finger raised)
"And our SECOND A word is — um —"
(long pause; glasses slide; he's really trying)
"— ant? Ant starts with A!"
```

```
SUNNY
(glances at Mia; both share a warm look — not laughing AT Leo, just a knowing smile
between friends)
```

```
SUNNY
(to Leo, warm, tilting head, genuinely kind)
"Ant DOES start with A! Big brain, Leo!"
(holds up one finger with a smile)
"But our word today is even MORE amazing."
```

```
SUNNY
(cups hands around mouth, looks UP dramatically — pointing at the sky above the fence)
"Let's look up!"
```

```
MIA
(grabs Leo's sleeve, whispers urgently, looking up)
"Look UP, Leo. Look up!"
```

[All three look up — a toy airplane on a string drifts over the fence, bobbing slightly in a breeze. The Chalk Word "AIRPLANE" floats in beside it.]

```
ALL THREE
(gasping in genuine delight — a single shared "OH!" — then together, loud and proud:)
"AIRPLANE!"
```

```
LEO
(laughing with pure relief, both hands out, grinning behind glasses)
"Airplane! Oh! A is for airplane! Not ant!"
```

```
SUNNY
(to camera, bouncing on her toes)
"Airplane — A — AMAZING!"
(spreads arms like airplane wings, tips side to side, zooming softly)
"Can you fly like an airplane?"
```

[PAUSE — 2 seconds — child spreads their arms at home]

```
SUNNY
(pointing finger-guns at camera, huge grin)
"You're flying! Airplane! You've GOT it!"
```

---

### REINFORCEMENT (10 seconds)

```
SUNNY
(claps a steady rhythm — CLAP CLAP CLAP — Leo and Mia join in)
"Let's say our A words TOGETHER!"
```

```
SUNNY
(rhythm clap)
"Apple!"
```

```
ALL THREE + [VIEWER JOINS]
"Apple!"
```

```
SUNNY
(rhythm clap)
"Airplane!"
```

```
ALL THREE + [VIEWER JOINS]
"Airplane!"
```

```
SUNNY
(rhythm clap — biggest one)
"A!"
```

```
ALL THREE + [VIEWER JOINS]
"A!"
```

```
MIA
(spinning one small circle, hands in the air)
"Amazing! That starts with A too!"
```

```
LEO
(pumping fist — the most un-Leo-like burst of energy — it's so satisfying)
"Apple! Airplane! A!"
```

```
SUNNY
(arms wide, looking straight at camera — EMOTIONAL CLOSURE)
"We did it. I feel SO proud of us."
```

```
EPISODE: EP01 "Ask Ask Ask"

SCENE: 3 of 5
SCENE PURPOSE: Song Lead-in
LOCATION: Sunny's Backyard → Camera Direct Address (LOC_DIRECT_ADDRESS)

EMOTIONAL BEAT GOAL: Building excitement, invitation to sing along

```

bouncing lightly on her toes, hands clasped under her chin)
"You know what we need right now?"
```

```
SUNNY
(throws arms wide and up, full commitment, looking straight into the lens)
"A SONG! An A-mazing A song!"
```

```
LEO
(runs into frame from camera-right, notebook tucked under arm, grinning the widest
grin we've ever seen from him)

```
MIA
(runs in from camera-left, grabs Leo's hand, skipping already)
"Me too! Me too!"
```

```
SUNNY
(steps toward camera, holds out both hands — an invitation to the viewer)
"Sing with us — ready?"
(takes a breath)
"Here we go!"
```

[STAR BURST TRANSITION — white flash from center frame, expands, contracts — MUSIC BEGINS: "A is Amazing"]

## SCENE 4 — SONG LEAD-OUT + RECAP

```
EPISODE: EP01 "Ask Ask Ask"
CONCEPT: Letter A | Apple, Airplane
SCENE: 4 of 5
SCENE PURPOSE: Song Lead-out / Recap
LOCATION: Camera Direct Address → Sunny's Backyard (LOC_BACKYARD)
CHARACTERS: Sunny, Leo, Mia
TARGET RUNTIME: 25 seconds
EMOTIONAL BEAT GOAL: Pride, celebration, warm and gentle wind-down
VIEWER INTERACTIONS: 1
```

### SONG LEAD-OUT (8 seconds)

```
SUNNY
(glowing, catching breath, directly at camera — she is genuinely happy, not
performing happy)
"Wow. You sang SO well."
```

```
LEO
(drops happily onto the bench, fans himself with notebook, big satisfied smile)
"That was the BEST song."
```

```
MIA
(still spinning one final slow circle, stopping with a dreamy grin)
"The best. The very best."
```

### RECAP (17 seconds)

```
SUNNY
(sits on the edge of the picnic table bench, leaning toward camera — warm, not
rushing, this is the moment that lands)
"So — what letter did we learn today?"
```

[PAUSE — 3 seconds — camera holds on Sunny's patient, encouraging expression; child answers]

```
SUNNY
(jumps up, both hands pointing at camera — pure joy)
"A! The letter A! You remembered!"
```

```
SUNNY
(holds up one finger — transition into recap beat, deliberate pace)
"A is for apple!"
(mimes a slow, satisfying crunch, smiling)
```

```
SUNNY
(holds up two fingers)
"And A is for airplane!"
(spreads arms wide like wings, dips one wing gently left, then right)
```

```
LEO
(standing, adjusting glasses, warm smile)
"And A is for amazing!"
```

```
MIA
(jumping up from bench)
"Like us!"
```

```
SUNNY
(turns to camera, voice soft, genuine, making eye contact with the viewer)
"Exactly like us."
(tiny pause)
"And exactly like YOU."
```

[WARM FADE TRANSITION — golden glow from edges, fading to the porch scene]

---

## SCENE 5 — GOODBYE

```
EPISODE: EP01 "Ask Ask Ask"
CONCEPT: Letter A | Apple, Airplane
SCENE: 5 of 5
SCENE PURPOSE: Goodbye
LOCATION: Sunny's Front Porch (LOC_SUNNY_PORCH)
CHARACTERS: Sunny (center — steps), Leo + Mia (background — porch level)
TARGET RUNTIME: 15 seconds
EMOTIONAL BEAT GOAL: Warmth, belonging, gentle ceremonial send-off
VIEWER INTERACTIONS: 1 (child waves back)
```

```
SUNNY
(seated on the top porch step, body turned slightly toward camera, at eye level with
the viewer — this is intimate, not performative; soft smile, unhurried)
"You did such a great job today, friend."
```

```
LEO + MIA
(visible behind Sunny on the porch level — Leo waves with one hand, Mia waves with
both, grinning)
"Bye! Bye bye!"
```

```
SUNNY
(to camera, deliberate, warm — one beat per concept word; each beat has a tiny
physical nod)
"We learned the letter A."
"Apple."
(soft crunch gesture)
"Airplane."
(one little wing-dip)
"Amazing."
(touches her heart)
```

```
SUNNY
(small pause, looking directly at viewer, smile growing slowly)
"Next time — we learn something just as fun."
```

```
SUNNY
(leans forward just slightly — close and genuine)
"Until then — you are amazing."
"Bye bye!"
```

[PAUSE — 2 seconds — Sunny waves slowly with both hands; Leo and Mia wave behind her]
[Camera begins a slow, gentle pull back — Sunny's wave fills the shrinking frame]

[MUSIC STING — outro; show logo animates in over the final wide]
```
