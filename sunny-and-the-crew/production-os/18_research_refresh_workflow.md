# Research Refresh Workflow (quarterly, or before each 5-episode batch)
1. Review top preschool channels' current formats (participation patterns, pacing, episode lengths) — note practices, never copy IP.
2. Check YouTube Kids policy updates (Made for Kids, quality principles for kids content).
3. Review our analytics: retention curve around 3s pauses, song vs setup drop-off, extended vs standard performance.
4. Feed findings into: episode template timings, segment mix, packaging template. Any change to LOCKED rules requires creator approval and a version bump in the affected doc.
