# Recurring Segment Specs (extended format modules)
ECHO PRACTICE (60-75s): step-down energy on porch -> model sound/word with big mouth shapes -> [3s pause] -> praise -> second louder round -> air-trace (letters) or gesture (concepts) -> celebrate. Bed: 90 BPM ukulele instrumental.
WORD/CONCEPT HUNT (90-100s): deputize viewer -> 3 finds (find -> closeup -> "does X start with/have...?" -> [3s pause] -> YES celebration -> chalk word) -> wrap with all 3 words + badge. Bed: 100 BPM pizzicato.
MOVEMENT REPRISE (song length): full song replays; ALL-NEW clips; one move per section, mirrored full-body instructional framing; ends with bow ("you did it").
Rules: segments are structured pedagogy, never filler; each has its own new clips; same QA as main parts.
