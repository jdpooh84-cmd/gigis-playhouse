# Shot Planning Template (per shot record)
shot_id (EP##-P#-S## or T##/A## for songs) | part | start/end (from cue sheet) | duration 3-5s | purpose (establish/emotion/interaction/support_lyric/participation/transition/outro) | location_id | characters (with element UUIDs) | action (one sentence, one event) | emotion | camera (angle+move, ONE move max) | motif (if any, per world rules) | lyric/dialogue line | kid_cue | asset_source (reuse id | needs_new) | transition (cut default).
Motion fields (added 2026-07-13, see 25_motion_pacing_rules): motion_tier (A active / B natural / C calm / SLOMO) | action_verb (the imitable verb, must match dialogue) | slomo_justification (required only if SLOMO). Default tier: story=B, lead-in/song/game=A, establish/goodbye=C. Motion-energy lever: genre:"action" on tier-A seedance renders (seedance_2_0 has NO speedramp param — verified 2026-07-13); kling3_0 for dance hero shots.
Design rules: one purpose per shot; max 4 principal characters unless ensemble beat; direct-to-camera reserved for invitations, questions, praise, goodbyes; scale rules always (Mimi smallest, Nana tallest); no Bella+Gabriel; silhouette-readable staging; palette consistent; no clutter (max 3 focal props).
