# Thumbnail Design Brief
## Gigi's Playhouse — Channel Standard + GP-001 Spec

---

## CHANNEL THUMBNAIL RULES (apply to all videos)

### Technical Specs
- **Size:** 1280 × 720 px (16:9)
- **Safe zone:** Keep all key content within 1200 × 640 px center (40px margin each side)
- **File format:** JPG or PNG, max 2MB
- **Small-size test:** Always preview at 120px wide (YouTube mobile) and 320px wide (tablet)

### Visual System
| Element | Rule |
|---------|------|
| Background | Solid bright color or simple gradient — no photographic backgrounds |
| Characters | 3D cartoon renders, occupying 50–65% of frame, left-center position |
| Text overlay | Bold, max 4 words, right side of frame, high-contrast outline |
| Color palette | 2–3 saturated colors only; never dark or desaturated backgrounds |
| Expression | Most extreme positive emotion possible — big eyes, open mouth, arms up |
| Brand mark | Small channel logo bottom-right corner |

### What Works
- Characters with exaggerated happy/surprised faces
- Clear emotional contrast (before/after, problem/solution)
- Bold single-color text with thick outline (white text, yellow outline OR yellow text, black outline)
- Stars, hearts, sparkle effects as accents
- Red nose or problem indicator for sick-day videos (signals the scenario instantly)

### What Doesn't Work
- Complex backgrounds that compete with characters
- Small characters lost in the frame
- Text that takes more than 1 second to read
- More than 3 colors
- Characters with neutral expressions
- Dark color schemes

## GP-001 THUMBNAIL SPEC: "WHAT SHOULD WE DO? / FEEL BETTER!"

### Chosen Scene
- **Scene reference:** SCN-029 (4:10–4:22) — Gigi and Boo waving together, fully recovered
- **Alternate candidate:** SCN-027 (3:50–4:00) — the hug close-up

### Primary Design Brief

**Background:**
- Warm sunshine yellow (#FFD700) solid background
- Optional: subtle radial gradient lightening toward center

**Characters:**
- Gigi left-center, 55% frame height, arms raised in "YAY!" pose
- Boo right-center, slightly smaller (younger), arms raised, big laugh face
- Both characters positioned slightly overlapping, creating connection
- Boo's red nose must be GONE in this shot (recovery complete)

**Text Overlay:**
- Main text: **"FEEL BETTER!"** 
- Font: Rounded, bold, slightly playful (Nunito ExtraBold or similar)
- Color: Bright white (#FFFFFF)
- Outline: Pink (#FF69B4), 8px stroke
- Shadow: Soft drop shadow for depth
- Position: Right third of frame, vertically centered
- Secondary text: "🎵 Nursery Rhyme" — smaller, beneath main text, pink

**Accents:**
- 3–4 small pink hearts scattered near characters
- Small sparkle/star effects near Boo
- Possible: small red nose with X over it (bottom left) as "problem solved" indicator

**Logo:**
- "Gigi's Playhouse" — bottom-right corner
- Small enough not to compete, but legible at 120px wide

### Color Palette for This Thumbnail

### Mobile Test
At 120px wide, this thumbnail must communicate:
- Two happy kids ✓

## TOOLS FOR THUMBNAIL CREATION

| Tool | Use Case |
|------|----------|
| Canva | Fast thumbnail — use their kids template as base, drop in character renders |
| Adobe Express | Similar to Canva, good for quick text overlay |
| Photoshop/Affinity | Full control — use when character renders are in PSD/PNG format |
| DALL-E/Midjourney | Generate scene image if no 3D render available yet |

### Quick Canva Workflow (No design tool experience needed)
1. New Design → Custom Size → 1280×720
2. Set background to #FFD700
3. Upload character PNGs (rendered from visual prompts)
4. Add text "FEEL BETTER!" — set to ExtraBold, white, pink outline
5. Add hearts from Canva elements
6. Export as JPG, max quality
7. Test at small size before uploading
