## Continuity Rules for Both Characters
- Always use the same prompt blocks above
- Maintain same relative size: Ziggy slightly wider, Bop slightly taller
- Both always appear in the same shots unless a solo close-up is needed
- Facial expressions change but character design stays identical
- Colors: never vary the base colors between scenes
- Style: flat 2D, NO 3D rendering, NO shadows or depth shading
