# output/ — Generated Assets Directory

## Status
Assets generated via Higgsfield are **cloud-hosted**. They cannot be downloaded directly to this filesystem from the generation API. All asset references (job IDs and output URLs) are tracked in:

```
../12-asset-manifest.md
```

## What This Directory Is For
If any Higgsfield asset supports direct file export/download in the future, or if you manually download assets from the Higgsfield dashboard, store them here using this naming convention:

```
char-max-jump.png
char-lily-spin.png
char-theo-robot.png
char-nina-clap.png
char-sam-fist.png
scene-groove-room-empty.png
scene-group-wide.png
scene-verse1-jump-clap.png
scene-verse2-spin-stomp.png
scene-verse3-wiggle-freeze.png
scene-outro-final.png
thumb-ep01.png
audio-chorus.mp3
audio-verse1.mp3
audio-verse2.mp3
audio-verse3.mp3
```

## How to Retrieve Assets
1. Open the Higgsfield dashboard
2. Find the job by job ID (listed in 12-asset-manifest.md)
3. Download the output file
4. Rename to match the convention above and save here

## Cloud Asset URLs
All cloud asset URLs are captured in `../12-asset-manifest.md` under each job entry.
